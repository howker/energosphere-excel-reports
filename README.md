# EnergySphere Excel Reports

Программа пакетного формирования паспортов присоединений по шаблону П-П1.

Текущее направление: импорт данных из Excel, выбор всех или отдельных
присоединений, формирование отдельных файлов и отображение прогресса.
Анализ БД остановлен по решению пользователя; SQL и прежние исследования
сохранены как материалы предыдущего этапа.

Проверка двух исходных книг и карта переноса: [docs/excel-import-plan.md](docs/excel-import-plan.md).
Полное приложение пока не реализовано.

План работ, изменения направления и причины: [BACKLOG.md](BACKLOG.md).
Бэклог ведётся в репозитории и коммитится вместе с изменениями проекта.
