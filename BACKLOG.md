# Бэклог разработки

Обновлено: 08.10.2026. Изменения направления и причины фиксируются здесь
и включаются в Git-коммит вместе с соответствующими изменениями проекта.

## Текущее направление

Автономная программа на Go для Windows: загрузить Excel установленной
структуры, выбрать все или отдельные присоединения и получить отдельные
паспорта по шаблону П-П1. Во время пакетного формирования показывать прогресс.

Основной источник — загруженный пользователем Excel. Значения переносим
из выбранного файла. Отсутствующие поля оставляем пустыми. Анализ
расхождений, сравнение версий и оценка актуальности данных сейчас не входят
в задачу. Даты форматируем без изменения календарного дня.

## Изменения направления и причины

### 08.10.2026 — переход с SQL-базы Энергосферы на Excel

**Было:** изучение CSD_Astrakhan на SQL Server 2008 R2, поиск источников
паспортных данных и подготовка выборки для будущего генератора.

**Стало:** импорт готовых структурированных Excel-файлов и пакетное
формирование паспортов. Подключение к SQL Server в первый рабочий выпуск
не включаем. Предыдущие SQL-запросы и результаты исследования сохраняем
как материалы завершённого исследовательского этапа.

**Причина:** пользователь сообщил, что исследуемая БД является старой
копией, а в имеющихся Excel-файлах есть свежие сведения. Структура файлов
содержит основные данные счётчиков, ТТ, ТН, поверок и присоединений,
поэтому прямой импорт соответствует текущей задаче и снимает необходимость
зависеть от сервера Энергосферы.

**Проверка возможности:** прочитаны обе книги. В большом файле выделено
373 присоединения на 18 объектах, в малом — три присоединения. Общая
структура основного листа совпадает: A:AF, блок присоединения из трёх строк,
объединённые общие поля и отдельные позиции оборудования.

### 08.10.2026 — прямой перенос значений без анализа расхождений

**Решение:** при импорте используем выбранный файл как самостоятельный
источник. Значения не исправляем и не подменяем по другой книге или базе.
Сопоставление заголовков и разбор формата нужны только для переноса данных;
интерфейс сравнения данных и проверки их актуальности сейчас не создаём.

**Причина:** прямое указание пользователя: «анализ расхождений не нужен пока.
просто берём данные из файла и выбрасываем в отчёт».

### 08.10.2026 — назначение двух исходных файлов

- `II-2026-Prilozhenie-No1.xlsx` — основной набор, 373 присоединения.
- `II-2026-Prilozhenie-No1 -3.xlsx` — используем как малый тестовый набор
  из трёх присоединений, которые также есть в большом файле.

**Причина:** пользователь уточнил, что малый файл, вероятно, подготовлен
для тестов. Его не считаем дополнительными тремя уникальными присоединениями
и не объединяем автоматически с основным набором.

### 08.10.2026 — целевая legacy-платформа и автономный EXE

**Решение:** Windows 7 / Server 2008 R2, x86 и x64, по прямому ответу
пользователя. Go 1.20.14, `CGO_ENABLED=0`, стандартная библиотека,
обычные элементы Win32. Excel, WebView, браузер, .NET и Python для запуска
программы не требуются. Исходный XLSX читается через ZIP/XML; форма и
рисунки встроены в EXE. Системный PATH не изменяется.

**Причина:** новые версии Go и современные оболочки GUI могут требовать
более новую Windows. На машине проверены `C:\Users\serg\sdk\go1.20.14`
(используется для сборки) и `C:\go-old\go` (Go 1.10.8, не используется).
Официальная граница совместимости:
[Go 1.20 release notes](https://go.dev/doc/go1.20#windows).

**Реализация формы:** выход — XLSX без VBA. Программа заполняет готовые
значения, заменяет макрос выбором видимости рисунка, сохраняет изображения,
векторные объекты, стили, размеры и исходные параметры печати. Из образца
удалены прежние сведения об оборудовании, нагрузки, пломбы и заключения.
Исходные строки сохранены на `исх.данные`; следующие поверки и свидетельства
доступны там. МПИ и неизвестные классы/номера Госреестра не вычисляются.
Заголовок блока ТН исправлен; старые приблизительные VLOOKUP не используются.

**Причина:** прямой перенос свежего файла и автономная работа на legacy ОС;
исполнение макроса и пересчёт формул заполненного образца не нужны.
