# Условный расчёт нагрузки измерительных цепей

По решению пользователя от 10.10.2026 поля формы содержат числа без знака «≈».
Основание расчёта и допущения вынесены на отдельный лист «расчёт нагрузки»
каждого паспорта и в справочник. Эти значения являются условной верхней
оценкой, а не результатом измерения нагрузки на объекте.

## Допущения и формулы

Для каждой имеющейся фазы приняты: один счётчик, медные провода,
20 м в одну сторону, сечение 4 мм², температура 20 °C,
двухпроводная петля и сопротивление контактов 0,02 Ом.
Сопротивление петли: R = 0,0175 × 2 × 20 / 4 + 0,02 = 0,195 Ом.
Вторичный ток берётся из знаменателя коэффициента ТТ; если он не распознан,
условно принимается 5 А. Фазное напряжение условно принято 57,7 В.

- ТТ: S = S токовой цепи счётчика + I вторичный² × R.
- ТН: S = S цепи напряжения счётчика + (S / 57,7)² × R.

Сложение модулей мощностей даёт консервативную верхнюю оценку при неизвестном
коэффициенте мощности. Прочие приборы, общий провод трёхфазных цепей и
суммарная нагрузка нескольких присоединений на общий ТН не моделируются.
Для ТН число относится к условной цепи одного присоединения, а не ко всей
обмотке общего трансформатора. Пустые фазы не заполняются.

Производители указывают предельное потребление, поэтому оценка может быть

поровну на три фазы. Для А1800 предельные 3,6 ВА приняты на фазу без
уточнения исполнения. Для неизвестных модификаций, включая ЕвроАльфа,
профиль не подтверждён паспортом конкретного прибора.

## Справочник для каждого присоединения

При выгрузке в выбранной папке создаётся «Справочник_нагрузок.csv»:
UTF-8 с BOM, разделитель — точка с запятой. Справочник содержит весь
загруженный список, даже когда для формирования паспортов выбрана его часть.
В большом предоставленном файле проверены 373 записи.

Шесть столбцов ТТ_A_ВА…ТН_C_ВА можно редактировать в Excel. Сохранённые
значения используются при следующей выгрузке в ту же папку. Новые
присоединения добавляются автоматически, существующие числа сохраняются.
Ключ включает общество, объект, присоединение, номер и тип счётчика.
После замены ТТ/ТН или изменения измерительных цепей нужно уточнить
соответствующие значения вручную либо пересоздать справочник.

Отрицательные, нечисловые, бесконечные значения и повторяющиеся записи
останавливают выгрузку с сообщением об ошибке. Папка со справочником должна
быть доступна для записи. При редактировании сохраняйте структуру столбцов.
