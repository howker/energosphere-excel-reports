У счётчика `SN=808090791`, но `SN_Display=0808090791`. Используем текстовое
отображаемое значение, иначе теряется начальный ноль.

ТН расположен под шиной СШ2: `48815.ID_Parent=48805`
(тип родителя подтверждён четвёртым экспортом).
Из целевого присоединения на него указывает ссылка 48848. Нельзя выбирать
оборудование только по непосредственным дочерним узлам.

У ТТ нет фазы B. У ТН одна запись с `Phase=NULL`; она не доказывает отсутствие
фаз B/C. Для выбора схемы учитывать тип оборудования и правила шаблона.

Тип ТТ задаёт первичный ток 30 А, но оба экземпляра переопределяют его на
50 А. Поэтому строковый атрибут объекта 136, собранный через
`MeaModuleTypeName`, показывает **30/5**, а реальные атрибуты экземпляров
дают **50/5**. Для полей паспортов приоритет имеют данные экземпляра.
Числовой коэффициент, полученный делением этих атрибутов, подтверждён;
работу штатных `MeaCoeff` / `MeaCoeffStr` ещё проверим по исходникам.

## Даты и отсутствующие поля

| Оборудование | DT_QC_Prev, как сохранено в БД | DT_QC_Next, как сохранено в БД |
|---|---|---|
| Счётчик | 2021-08-04T23:00:00 | 2033-08-04T23:00:00 |
| ТТ A | 2022-07-14T23:00:00 | 2026-07-14T23:00:00 |
| ТТ C | 2022-07-04T23:00:00 | 2026-07-04T23:00:00 |
| ТН | 2019-07-10T23:00:00 | 2024-07-09T23:00:00 |

В образце счётчик имеет дату 05.08.2021, а его значение БД — предыдущий
день в 23:00. Это указывает на возможное преобразование времени при
отображении, но не доказывает конкретный часовой пояс хранения дат.
Нельзя просто отрезать время или автоматически прибавить сутки.
Часы базы в снимке приблизительно на три часа впереди UTC, тогда как
образец сообщает UTC+4. Следующий запрос выгружает настройку смещения
и доступные функции преобразования времени. Текущий UTC_Bias сам по себе
не доказывает соглашение о хранении каждой даты поверки.

Название шины: атрибут 103 возвращает NULL. В цепочке родителей узла
типа 8 нет, дополнительных связей у целевого счётчика в этом снимке нет.
`СШ1` из образца автоматически не подставляем. Вид учёта подтверждён:
`Технический`, дополнительный атрибут 3 счётчика.

Нагрузка, пломбы, подписи и дата допуска из констант образца не подтверждены
этой выгрузкой. При требовании «всё из ЭС» они остаются незаполненными,
пока не найден соответствующий источник в базе.
