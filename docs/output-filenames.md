# Имена файлов паспортов

Обновление 08.10.2026: текущий источник — Excel. Для него имя строится по
обществу, объекту и полному названию присоединения из B, C и E. Общий верхний
префикс может задаваться для партии. Ниже сохранены результаты прежнего
исследования БД; её иерархия при импорте Excel не используется.

Требование пользователя от 08.10.2026: имя содержит всю цепочку присоединения
с верхнего уровня. Пример базового имени без расширения:

`Астраханский ГПЗ ГПП-1 ЗРУ 6кВ№1 яч.1 РП-17`

Генератор получает упорядоченные уровни дерева вместе с их ID и названиями,
соединяет названия одним пробелом и добавляет расширение выходного формата.
Присоединение включается последним. Дочерний счётчик и оборудование в имя
не входят. Кириллица, знак №, дефисы и точки сохраняются. Отображаемые
названия не заменяются заводскими номерами или ID.

Первый источник — цепочка `Points.ID_Parent` от выбранного присоединения
к верхнему родителю. Третий диагностический экспорт возвращает её в
`connection_path` в порядке от верхнего уровня и текст `full_connection_path`.
Он также возвращает `PointRelations`, чтобы проверить связи альтернативного
дерева и возможное отличие пути от отображения в Энергосфере. Дополнительные
связи не добавляются в имя произвольно.

Для Windows символы `< > : " / \ | ? *` и управляющие символы нельзя
оставлять в имени файла; генератор должен заменить их пробелом, убрать
повторные пробелы и конечные точки/пробелы. Исходный путь должен сохраняться
в данных отчёта независимо от преобразования имени.

При совпадении полученных имён нельзя перезаписывать чужой паспорт.
Допустимый способ различить файлы — добавить ID присоединения к полной
цепочке и сообщить об этом. При превышении доступной длины пути нельзя
молча обрезать уровни: нужно показать полный путь и предложить более
короткую выходную папку либо явно согласованное сокращение.

Путь присоединения 48803 проверен по третьему XML и совпал с основной
цепочкой PointRelations. Точное базовое имя приведено в
`passport-48803-analysis.md`. Генератор файлов ещё не реализован.
