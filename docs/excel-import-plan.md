# Пакетные паспорта из Excel

## Принятое направление

08.10.2026 пользователь остановил направление с БД и предложил Excel как
источник свежих сведений. Дополнительное указание: анализ расхождений сейчас
не нужен — берём значения выбранного файла и переносим в отчёт.

Программа должна загружать файл, показывать присоединения, позволять выбрать
все или некоторые, формировать отдельные отчёты пачкой и показывать прогресс.
Имя отчёта сохраняет полную доступную цепочку присоединения сверху вниз.

## Проверенная возможность импорта

Прочитаны оба исходных XLSX без изменения и пересохранения:

| Файл | Присоединения | Объекты | Строки данных основного листа |
|---|---:|---:|---|
| II-2026-Prilozhenie-No1 -3.xlsx | 3 | 1 | 10–18 |
| II-2026-Prilozhenie-No1.xlsx | 373 | 18 | 10–1128 |

По уточнению пользователя малую книгу используем как тестовый набор:
её три присоединения также входят в большую. Основной набор содержит
373 записи; автоматически складывать количества или объединять книги не нужно.

Основной лист в обоих файлах: `Прил.1.1 (Сч,ТТ,ТН)`, 32 столбца A:AF.
Все найденные присоединения представлены блоками из трёх строк.
Общие поля и счётчик объединены вертикально; сведения о ТТ/ТН расположены
в строках внутри блока. Границы определены по объединениям названия
присоединения в E, а не делением общего количества строк на три.

Служебные заголовки 1–9 и пояснения после последнего блока в список
присоединений не попадают. Другие листы книги относятся к УСПД/УССВ/АИИС,
энергоресурсам и вспомогательным данным; для основного импорта не нужны.

В пробном разборе сохранены отдельные позиции оборудования и исходные
адреса ячеек. Учитываются объединённые ячейки, переносы строк, текстовые
и числовые номера, текстовые даты и даты Excel. Номера остаются строками,
ведущие нули в текстовых номерах сохраняются.

Это подтверждает возможность автономного импорта без подключения к БД.
Импорт и генератор реализованы на Go 1.20.14. Получены и независимо
проверены 373 выходных книги. Подробности запуска и ограничения печати —
в README и бэклоге.

## Карта переноса

| Сведения | Столбцы источника |
|---|---|
| Дочернее общество | B |
| Объект | C |
| Инвентарный номер | D |
| Полное название точки присоединения | E |
| Напряжение | F |
| Вид учёта | G |
| Счётчик: тип, номер, класс, год выпуска | H:K |
| Счётчик: текущая и следующая поверки, свидетельство | L:N |
| ТТ: тип, отношение первичного/вторичного тока, номер, класс, год | O:S |
| ТТ: текущая и следующая поверки, свидетельство | T:V |
| ТН: тип, отношение первичного/вторичного напряжения, номер, класс, год | W:AA |
| ТН: текущая и следующая поверки, свидетельство | AB:AD |
| Участие в информационном обмене и принадлежность | AE:AF |

Даты выводятся календарными датами из файла, без часовых сдвигов.
Дата следующей поверки берётся из своего столбца. Типы, классы, отношения
и номера переносятся из выбранного файла. Значения одного файла не
замещаются значениями другого или старой базы.

Исходные позиции трёх строк сохраняются, включая пропуски в средней строке.
Букв A/B/C в заголовках этих строк нет: для шаблона предлагается порядок
сверху вниз A/B/C как явно заданное правило формата импорта. До реализации
этого правила позиции не выдаются за подписанные в Excel фазы.
Повтор одного номера ТН в нескольких строках сохраняется для фазового
представления и не превращается в несколько разных физических приборов.

Отдельного столбца МПИ в годах нет. Не подменяем его автоматически разностью
дат. Отдельные классы активной/реактивной энергии также не заданы двумя
столбцами: сохраняем класс из J без придумывания второго значения.
Поля шаблона, отсутствующие в источнике, остаются пустыми. Сведения о
пломбах, нагрузках, допуске и подписи не копируются из заполненного примера.

## Программа

Один рабочий экран:

1. «Открыть Excel» — выбор источника и чтение таблицы.
2. Таблица присоединений: флажок, объект, полное название, номер счётчика.
3. Поиск и фильтр по объекту. «Выбрать все», «Снять выбор», счётчик выбранных.
4. Выбор папки отчётов и команда «Сформировать».
5. Прогресс: обработано / выбрано, процент, название текущего присоединения.
6. Завершение: сколько файлов создано, кнопка открытия папки.

Формирование выполняется в фоне, интерфейс остаётся доступным. Отмена
останавливает очередь между отчётами и сохраняет уже завершённые файлы.
Ошибка чтения/записи конкретного отчёта фиксируется с его названием;
остальные выбранные отчёты продолжают формироваться. Прогресс считается
по завершённым попыткам обработки, а успешные и неуспешные файлы учитываются
отдельно. Проверки актуальности данных и сравнения версий в эту очередь
не входят.

## Имена и шаблон

Основа имени из доступных полей: общество B + объект C + полное название E.
Название E сохраняется целиком, включая РУ, шину и ячейку, если они указаны.
Общий верхний префикс, например «Астраханский ГПЗ», можно задать один раз
для партии; автоматически приписывать его всем объектам из книги нельзя.
Предпросмотр имени показывается до формирования. Запрещённые для имени
файла символы заменяются, совпадающие имена получают суффикс номера записи.

Форма паспорта остаётся основанной на П-П1. Для прямого заполнения требуется
записывать поля источника и оборудование по позициям; старые формулы поиска
по справочникам шаблона не должны подменять название объекта и параметры
из загруженного файла. Выбор схемы определяется составом оборудования.

При реализации на Go удобно разделить импорт XLSX, модель паспорта,
заполнение шаблона и очередь формирования с событиями прогресса. Это
позволит использовать один импорт для всего файла и выдавать выбранные
отчёты без повторного чтения книги для каждого присоединения.

## Что проверено

Пробный разбор двух книг выделил 3 и 373 блока, сохранил порядок строк
оборудования и не включил заголовки/пояснения в данные. Основные поля
паспортов сопоставлены со столбцами. Исходные книги не изменены.
Реализован генератор: проверены 373 выходных книги, выбор одного/двух
присоединений, GUI x86/x64 и сохранение рисунков/стилей. Открытие в Excel
прошло без восстановления. Настройки печати исходного шаблона дают десять
страниц A4, включая пустые; печатный выпуск требует согласования макета.
